# মাপখাতা (MapKhata)

বাংলাদেশের বুটিক হাউস, টেইলার্স ও কাস্টম ড্রেস মেকারদের জন্য মোবাইল-ফার্স্ট SaaS অ্যাপ।

সমস্যা যা সমাধান করে: হারিয়ে যাওয়া কাগজের মাপের খাতা, প্রতিদিনের "আমার ড্রেস কি রেডি?" ফোন কল, কাস্টমারের বকেয়ার হিসাব না থাকা, আর কারিগরের পিস-রেট মজুরির ভুল হিসাব।

## যা যা আছে (ক্রমে তৈরি হচ্ছে)

- ড্যাশবোর্ড — বিকাশ-ধাঁচের ক্লিন হোম: সবুজ ব্যান্ড, "আজকের হিসাব" পিল, গোল আইকন অ্যাকশন গ্রিড, আজকের ডেলিভারি তালিকা
- অর্ডার — স্ট্যাটাস ফিল্টারসহ (মাপ নেওয়া → কাটিং → সেলাই → রেডি → ডেলিভারি সম্পন্ন)
- বকেয়া — কাস্টমার অনুযায়ী বকেয়া তালিকা, পুরনো আগে, এক ট্যাপে জমা
- কারিগর — পিস-রেট অনুযায়ী কাজ, আয় ও পাওনার হিসাব
- আসছে: নতুন অর্ডার + পোশাকভিত্তিক মাপের ফর্ম, কাস্টমার তালিকা, SMS নোটিফিকেশন, কাস্টমার ট্র্যাকিং লিঙ্ক

## টেক স্ট্যাক

- React Native (Expo SDK 58) + TypeScript + Expo Router
- ফন্ট: Hind Siliguri
- ব্যাকএন্ড (আসছে): Supabase (PostgreSQL + RLS), SMS গেটওয়ে
