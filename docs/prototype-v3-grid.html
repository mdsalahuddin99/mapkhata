মাপখাতা হোম v3 — গোল আইকন গ্রিড (আপনার পছন্দমতো)

বিকাশের কাঠামো হুবহু: উপরে সবুজ ব্যান্ডে দোকান + "আজকের হিসাব" পিল, নিচে সাদা শিটে ৪-কলামের গোল আইকন গ্রিড, বটম নেভিগেশনের মাঝে বড় গোল + বাটন (নতুন অর্ডার)। তফাৎ শুধু: আইকনের রঙ আমাদের শান্ত প্যালেট থেকে, বিজ্ঞাপনের ব্যানার নেই, ব্যান্ড ফ্ল্যাট।
